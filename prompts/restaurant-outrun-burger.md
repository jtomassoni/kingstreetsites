# Outrun Burger Demo Site Prompt

Build a premium, mobile-first marketing website for a ghost kitchen burger brand called Outrun Burger.

## Business and audience
- Business type: Ghost kitchen and delivery-first burger brand
- Audience: Late-night diners, mobile users, urban professionals, students, delivery-heavy customers
- Core conversion goal: Drive direct online orders and reduce friction to order

## Positioning and tone
- Tone: Bold, stylish, modern, slightly edgy, clear, practical
- Do not sound cheesy or overhyped
- Prioritize action-focused copy above the fold

## Design direction
- Late-night energy with premium restraint
- Strong typography and generous spacing
- Dark, cinematic palette with focused accent color
- Cards, shadows, and rounded corners should feel intentional and polished
- Use icons consistently where visual reinforcement helps
- Do not use emojis

## Above-the-fold priorities
- Headline that communicates direct ordering value immediately
- Supporting copy focused on speed, quality, and convenience
- Primary CTA: Order Now
- Secondary CTA: View Menu
- Keep core conversion messaging and CTA fully visible on mobile hero

## Required sections
- Hero with clear order CTA
- Menu highlights with featured burgers, sides, and bundles
- Direct order benefits section
- About the brand section
- Location and availability section
- FAQ section
- Repeated sticky or persistent order CTA

## CTA strategy
- Primary CTA: Order Now
- Secondary CTA: View Menu
- Optional tertiary CTA: Late Night Hours
- Use repeated, tasteful CTA placements throughout the page

## Trust signals
- Realistic customer rating summary
- Clean delivery time expectations
- Ingredient and quality statements
- Social proof snippets

## Mobile and UX behavior
- Mobile-first layout and spacing
- Sticky mobile CTA bar for Order Now
- Tap targets sized for fast ordering behavior
- Fast loading and simple navigation

## Accessibility requirements
- Strong semantic HTML and heading hierarchy
- Visible keyboard focus states
- Sufficient color contrast
- Accessible labels for all controls

## Motion and visual continuity
- Use restrained animations for section entrances
- Include subtle scroll cue in hero to suggest content below the fold
- Keep animation premium and never distracting

## Image and placeholder requirements
- Use intentional image slots throughout the design
- Every placeholder image alt text must be descriptive enough to reuse as an AI image or stock sourcing prompt
- Example alt text style: "moody late-night burger and fries on a stainless steel counter with neon reflections and dark cinematic lighting"

## Form behavior expectations
- Include an email or SMS signup style form for promotions
- Form can be frontend-only for now
- Must validate inputs
- Must show loading state
- Must show polished success state
- No real backend required for this demo

## Technical expectations
- Build with modern component structure
- Keep code clean and reusable
- Site only needs to appear functional for now
- No production backend required
